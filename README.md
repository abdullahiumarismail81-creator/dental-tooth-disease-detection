# Dental Tooth Disease Detection System

A Deep Learning and Computer Vision project designed to detect dental health conditions from dental images.

## Detectable Conditions

- Dental Caries (Cavities)
- Gingivitis
- Tooth Discoloration
- Oral Ulcer

## Features

- Image Upload
- Disease Detection
- Confidence Scoring
- Condition Visualization
- Streamlit User Interface

## Technologies Used

- Python
- Streamlit
- Roboflow Inference SDK
- PIL
- JSON
